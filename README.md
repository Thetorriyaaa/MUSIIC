Использование GPT

В процессе разработки GPT использовался как вспомогательный инструмент для работы с кодом. Он помогал разбираться в отдельных технических моментах, искать решения возникающих проблем и улучшать работу интерфейса. Полученные решения проверялись и дорабатывались по ходу создания проекта.
